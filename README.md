# Neon Triqui JS

Minijuego web interactivo de **3 en raya (triqui)** con estilo **neón/cyberpunk**, desarrollado en un solo archivo HTML con CSS y JavaScript integrados.

## Características

- Diseño moderno, llamativo y **responsive**.
- Modo **Jugador vs IA**.
- Dificultades: **Fácil, Normal y Difícil**.
- Marcador de **victorias, derrotas y empates**.
- Control de rondas y reinicio rápido de partida.

## Tecnologías

- HTML5
- CSS3 (estilos personalizados, efecto glass/neón)
- JavaScript (lógica del juego + IA con Minimax en difícil)

## Cómo ejecutar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/DavidSaavedraDev/juego-triqui-js.git
   ```
2. Entra a la carpeta:
   ```bash
   cd juego-triqui-js
   ```
3. Abre el archivo `minijuego-3enraya-neon.html` directamente en tu navegador.

No requiere instalación de dependencias ni servidor local.
